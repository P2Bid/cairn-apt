# Журнал изменений cairn

Что нового в каждом выпуске — одной строкой от лица того, кто cairn пользуется.
Собирается `tools/changes-assemble.sh` из фрагментов каталога `changes/` при выпуске;
новый выпуск встаёт сверху. Править руками можно, но следующий выпуск встанет над правкой.

## 2026.09.22

- Нижняя строка окна Claude Code называет установленную версию cairn всегда, а не только когда вышла новее: увидеть, что обновление доехало, теперь можно молча посмотрев на строку.
- Вышла версия новее — рядом её номер и команда, которой обновляются; разошлась сборка живой службы провода с установленным файлом — строка говорит и об этом, и называет команду перезапуска.
- В узком окне ряд о версии укорачивается сам: сперва уходят поля, потом сокращается сам номер, — а не обрывается на середине.

## 2026.09.21

- Статусная строка Claude Code говорит, что вышла новая версия cairn, а `cairn update` называет её номер и что добавлено, спрашивает согласия и одним ходом обновляет пакет, уровень и провод.
- `cairn doctor` в разделе обновлений отвечает, есть ли версия новее, — и называет причину, когда ответить нечем: apt не ответил вовремя, база пакетов повреждена или списки давно не обновлялись.
- `cairn install`, не сумевший разложить уровень, говорит об этом кодом возврата, а не молча выходит нулём.
- `cairn adr new` больше не выдаёт номер, который уже занят файлом в любой вашей ветке.
- Уборка `cairn tidy` видит и убирает рабочие копии, заведённые Claude Code, а не только свои.
- Каталог `.claude/` больше не попадает в репозиторий: его ведёт Claude Code, а не проект.

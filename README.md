# Витрина APT для cairn

Репозиторий APT, из которого ставится `cairn`. **Порождается задачей «выпуск пакета»**
в `P2Bid/cairn`; правки руками теряются при следующем выпуске.

## Как подключить

Один файл, `/etc/apt/sources.list.d/cairn.sources`. Ключ вкладывается прямо в него
полем `Signed-By` — отдельный keyring не нужен (формат deb822, apt ≥ 2.4):

```
Types: deb
URIs: https://p2bid.github.io/cairn-apt
Suites: jammy
Components: main
Signed-By:
 <сюда — содержимое cairn.asc, каждая строка с одним пробелом в начале>
```

`Suites` — кодовое имя своего выпуска Ubuntu: `jammy` (22.04), `noble` (24.04) или
`resolute` (26.04). Узнаётся разбором `/etc/os-release`:
`. /etc/os-release; echo "$VERSION_CODENAME"`. Не `lsb_release` — его в минимальной
системе и в контейнере обычно нет.

Дальше:

```
sudo apt update && sudo apt install cairn
cairn install          # один раз, ОТ СЕБЯ, а не от root
```

**`cairn install` не зовётся установкой пакета намеренно:** он раскладывает уровень в
домашний каталог человека, а скрипт пакета идёт от root.

Кто предпочитает ключ отдельным файлом — берёт `cairn.asc` отсюда же, кладёт в
`/etc/apt/keyrings/` правами **644** (файл читает системный пользователь `_apt`) и пишет
`Signed-By: /etc/apt/keyrings/cairn.asc`.

## Что здесь лежит

- `dists/<suite>/` — подписанные индексы по выпускам Ubuntu;
- `pool/` — сами пакеты;
- `cairn.asc` — открытый ключ, которым подписаны индексы;
- `conf/` — настройка `reprepro`, переписывается выкладкой при каждом выпуске.

## Чего здесь нет

Архитектура одна — **amd64**. ARM не собирается и в индексе не объявлен.

Двоичный файл виден всякому, кто знает этот адрес: репозиторий публичный, потому что
из закрытого пакеты через `apt` не отдаются вовсе. Исходники cairn при этом остаются
закрытыми.
